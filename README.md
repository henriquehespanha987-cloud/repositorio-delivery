# Prime Burger — reprodução do cardápio

Projeto de demonstração baseado no HTML da página inicial fornecido no chat. A página inicial preserva sua estrutura, textos e links internos.

**Importante:** as páginas internas, os estilos e os scripts que não estavam no arquivo enviado são recriações funcionais, não cópias exatas. As imagens e o CSS original são referenciados por URLs de primeburguer.delivery porque os arquivos binários e folhas de estilo originais não puderam ser baixados. Se essas URLs estiverem indisponíveis, alguns recursos visuais poderão falhar.

O checkout é uma simulação local e **não recebe pagamentos**, não gera QR Code Pix nem envia dados de clientes. Scripts de rastreamento de terceiros não foram habilitados. Claims de avaliações, estoque e promoções do HTML enviado não foram verificados.

## Estrutura
- `index.html` página principal
- `prime-individual/`, `combo-casal/`, `prime-familia/`, outras páginas de hambúrguer com seletor de adicionais e refrigerantes
- `checkout.html` carrinho local sem pagamento
- `css/`, `js/` estilos e comportamento de reserva
- `ARQUIVOS_ORIGINAIS_PENDENTES.md` lista dos arquivos que faltam para cópia exata
