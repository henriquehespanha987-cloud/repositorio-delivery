# Arquivos originais pendentes

O arquivo enviado pelo usuário contém a página inicial, mas não as páginas internas ou os recursos originais completos.

Arquivos necessários para cópia independente e byte a byte: `css/delivry.css`, `css/newcss.css`, os demais `js/*.js`, as imagens binárias de `images/` e `img/`, os 12 `index.html` das pastas de produto e o checkout original.

O `index.html` foi convertido do código fornecido e ajustado para referenciar imagens e CSS no domínio público de origem. O arquivo `css/fallback.css` oferece um visual de reserva. Scripts de rastreamento e coleta externos foram desativados. Páginas internas e carrinho são recriações, sem processamento de pagamento. Itens como avaliações, alegações promocionais, status aberto e disponibilidade precisam de confirmação independente antes do uso comercial.
